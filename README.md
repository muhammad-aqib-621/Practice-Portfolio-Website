## ✨ What Is This?

**Portfolio OS** is a premium, highly interactive personal frontend developer portfolio designed to *feel* like a digital operating system. Instead of just describing my frontend skills, the site itself **is** the demonstration — every scroll, click, and keystroke is part of the experience.

> 💡 Built with pure frontend technologies. No backend. No database. No servers. Just engineering and craft.

## 🚀 Signature Features

### 💻 Functional Terminal
A real, usable command-line interface baked into the portfolio.

```bash
$ help        # list all available commands
$ about       # who I am
$ projects    # view selected work
$ skills      # toolbox breakdown
$ lab         # jump to experiments
$ contact     # open contact section
$ resume      # view/download resume
$ status      # current availability
$ whoami      # identity snapshot
$ trace       # view your digital trace
$ clear       # clear terminal output
$ home        # return to hero
```

### 🌌 Digital Trace
A **session-local generative artwork** that visually evolves based on *your* interaction with the site — sections explored, projects viewed, lab experiments used, and terminal commands run.

> 🔒 Fully client-side. No data is ever sent to a backend or stored beyond your session.

### 🧪 The Lab
A playground of polished, original interactive experiments:

| Experiment | Description |
|---|---|
| ✨ Particle Field | Reactive particle system |
| 🧲 Magnetic Type | Typography that responds to cursor movement |
| 🎨 Color Engine | Dynamic, generative color exploration |
| 🪐 Orbit | Physics-inspired orbital motion |

### 🎭 Multi-Theme Support
Switch between three distinct visual moods — persisted locally so it remembers your preference.

| Theme | Vibe |
|---|---|
| 🌃 Midnight | Deep, dark, cinematic |
| 📄 Paper | Clean, editorial, light |
| ⌨️ Terminal | Retro-technical, monospace-driven |

### 📬 Contact — Powered by EmailJS
No backend required. Direct, secure delivery straight to my inbox.

```
Visitor → React Form → EmailJS → Inbox
```

**Form fields:**
- Name
- Email
- Project Type
- Message
- Budget / Timeline *(optional)*

## ⚙️ Environment Variables

Create a `.env` file in the project root:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

> ⚠️ Never commit your `.env` file. Add it to `.gitignore`.

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/muhammad-aqib-621/portfolio-os.git

# Navigate into the project
cd portfolio-os

# Install dependencies
npm install

# Add your environment variables
cp .env.example .env

# Run the development server
npm run dev

# Build for production
npm run build
```
